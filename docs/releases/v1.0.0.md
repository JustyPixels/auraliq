# Auraliq v1.0.0 — MVP Release

> **Your music. Your frequency.**

Auraliq **v1.0.0** is the first public MVP release of the 1990s retro-inspired desktop music hub built with **Rust + Tauri v2**.

---

## Highlights

- **Local-First Music Engine**: SQLite + WAL + FTS5 full-text indexing, incremental batched folder scanning, `lofty` tag & cover art extraction, M3U/M3U8/PLS import/export, smart playlists, collections, and non-destructive duplicate detection.
- **Native Rust Audio & DSP**: Dedicated `symphonia` + `cpal` playback thread with 5-band stereo biquad Equalizer, 6 presets, ReplayGain normalization, **Gapless Playback**, **Crossfade (0–8s)**, Windows SMTC media keys (`souvlaki`), and 5 `realfft` Canvas visualizers (Segmented LED Bars, CRT Scope, Cassette Deck, Dual Analog VU Meters, CRT Matrix).
- **Zero-Key & BYOK Online Music**: Out-of-the-box streaming from **Audius**, **Internet Archive**, **Radio Browser**, and **Direct HTTPS Audio URLs**, plus optional Bring-Your-Own-Key integrations (**Jamendo**, **Freesound**, **YouTube Data API v3** external watch handoff) stored in Windows Credential Manager (`keyring`).
- **Source-Aware Download Manager & LRU Cache**: Resumable HTTP `Range` downloads exclusively for permitted open/CC sources with `lofty` auto-tagging, plus a strictly separated LRU Temporary Playback Cache with **Offline Mode**.
- **Optional Opt-In Lyrics**: Offline `.lrc` sidecar loading + optional opt-in LRCLIB synced/plain lyrics with click-to-seek.
- **1990s Retro Purplish Deck UI**: Zero-radius beveled panels, 3D hardware controls, 5 built-in presets, 10-color palette overrides, typography presets, sanitized `<style id="auraliq-user-css">` live CSS editor, and JSON theme import/export.

## Security & Audit Summary

- `cargo audit` & `pnpm audit`: **0 known vulnerabilities** (`rusqlite 0.43` / `libsqlite3-sys 0.40.0`, `vitest 4.1.12`).
- Least-privilege Tauri v2 capabilities (`core:default`, `dialog:default`), restrictive CSP, SSRF URL blocklist, Windows reserved filename sanitization, and zero telemetry.

## Windows Installation & Verification

- **Installer**: `Auraliq_1.0.0_x64-setup.exe` (current-user NSIS installer, Windows 10/11 x64).
- **Portable**: `Auraliq_1.0.0_x64-portable.zip` (extract and run `auraliq.exe`).
- **Verify SHA-256**:
  ```powershell
  Get-FileHash .\Auraliq_1.0.0_x64-setup.exe -Algorithm SHA256
  Get-FileHash .\Auraliq_1.0.0_x64-portable.zip -Algorithm SHA256
  ```
  Compare against `SHA256SUMS.txt`.
